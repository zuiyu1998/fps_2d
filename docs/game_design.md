# FPS 2D - 游戏设计文档

> 一款类似《以撒的结合》的 2D top-down 射击 roguelike 游戏。

---

## 1. 游戏概述

### 1.1 核心概念

玩家操控一名角色在随机生成的地牢中探索、射击敌人、收集道具、击败Boss。每次闯关的地图、敌人、掉落道具都是随机的，保证每次游戏体验都不同。

### 1.2 游戏类型

- **类型**: Roguelike + Top-down Shooter + Arena Survival
- **视角**: 俯视 2D（top-down）
- **战斗方式**: 2D 平面射击（子弹沿水平/垂直方向发射）
- **核心循环**: 探索楼层 -> 清理房间 -> 击败Boss -> 进入下一层

### 1.3 参考游戏

| 游戏 | 借鉴点 |
|------|--------|
| 《以撒的结合》 | 地牢生成、道具系统、角色属性成长 |
| 《Enter the Gungeon》 | 子弹射击手感、弹幕设计 |
| 《Spelunky》 | 随机关卡生成、风险/回报机制 |
| 《Nuclear Throne》 | 快节奏战斗、高难度 |

## 2. 核心玩法

### 2.1 操控方式

| 操作 | 按键 |
|------|------|
| 移动 | WASD / 方向键 |
| 射击 | 方向键（子弹沿按键方向发射）/ 鼠标瞄准 + 左键 |
| 交互 | E / Enter |
| 道具切换 | 1 / 2 |
| 暂停 | Escape |

### 2.2 战斗系统

#### 2.2.1 伤害公式

```
实际伤害 = 攻击力 * 伤害倍率 - 敌人防御力
实际伤害 = max(1, 实际伤害)  # 最小伤害为 1
```

#### 2.2.2 伤害类型

- **普通伤害**: 默认伤害类型
- **真实伤害**: 无视防御
- **火焰伤害**: 附加持续灼烧效果
- **冰冻伤害**: 附加减速效果

### 2.3 角色属性

| 属性 | 说明 |
|------|------|
| 生命值 (HP) | 角色血量上限，归零即死亡 |
| 移速 (Speed) | 角色移动速度 |
| 攻击力 (Damage) | 每次射击的基础伤害 |
| 射速 (Fire Rate) | 射击间隔（帧数） |
| 射程 (Range) | 子弹飞行距离 |
| 弹速 (Projectile Speed) | 子弹飞行速度 |
| 幸运 (Luck) | 影响掉落、暴击、稀有事件概率 |

### 2.4 生命值系统

```
总血量 = 红心 + 黑心 + 灵魂心 + 血心
```

| 心类型 | 说明 |
|--------|------|
| 红心 | 普通生命值，可被拾取补满 |
| 黑心 | 伤害更高（双倍受伤），死亡后掉落黑心碎片 |
| 灵魂心 | 蓝色虚影心，被击中后短暂不回复 |
| 血心 | 红色暗面心，需要特定道具解锁 |

初始血量: **6颗红心（12 HP）**

## 3. 关卡设计

### 3.1 楼层结构

每层关卡由若干**房间**通过**通道**连接组成。

```
楼层结构:

  ┌─────┐     ┌─────┐
  │ 入口 │────▶│ 普通 │────┐
  └─────┘     └─────┘    │
                          ├──▶ Boss房
  ┌─────┐     ┌─────┐    │
  │ 商店 │────▶ 特殊 │────┘
  └─────┘     └─────┘

  入口 -> 普通房间组 -> Boss房
  部分楼层插入商店/特殊房间
```

#### 3.1.1 房间类型

| 房间类型 | 数量占比 | 说明 |
|----------|---------|------|
| 普通房间 | ~50% | 有敌人等待清理 |
| 空房间 | ~20% | 无内容，可能有拾取物或秘密入口 |
| Boss房间 | 1/层 | 本层最终敌人，击败后解锁出口 |
| 商店房间 | 每2~3层1次 | 可购买道具、补给 |
| 特殊房间 | ~10% | 事件房间、迷你Boss、奖励房 |
| 秘密房间 | ~5% | 需要特定方式发现，含稀有奖励 |

#### 3.1.2 楼层递进

| 楼层 | 主题 | 敌人类型 | 难度曲线 |
|------|------|---------|---------|
| 1F | 地下室 | 基础敌人 | 入门 |
| 2F | 洞穴 | 飞行敌人增加 | 中等 |
| 3F | 深渊 | 精英敌人出现 | 困难 |
| 4F | 炼狱 | 高难度混合 | 极难 |
| B1+ | Boss后地牢 | Boss强化版 | 超高难度 |

### 3.2 地牢生成算法

使用**房间放置 + 路径保证**的混合算法：

1. 确定本层房间数量和类型分布
2. 使用随机游走（Random Walk）或 BSP 分割生成房间位置
3. 使用最小生成树（MST）保证所有房间连通
4. 放置 Boss 房在最末端
5. 放置商店房在中间区域
6. 随机挖出秘密房间并标记隐藏入口

### 3.3 房间布局

每个房间由 `11x11` 的瓦片组成：

```
  01234567890
  ┌──────────┐
0 │..........│  ← 天花板
1 │··········│
2 │···XXXXXXX··│ ← 敌人出现区域
3 │···X    X··│
4 │···X  ###X··│ ← 房间中央，# = 可破坏障碍
5 │···X    X··│
6 │···XXXXXXX··│
7 │··········│
8 │······█····│  ← 门 (█)
9 │──────────│  ← 地板
  └──────────┘
```

- `.` = 天花板（不可进入）
- `·` = 地面（可进入）
- `X` = 墙壁（不可穿过）
- `#` = 可破坏障碍（箱子、石头等）
- `█` = 门（连接通道）
- `@` = 玩家出生点

## 5. 道具系统

### 5.1 道具分类

| 类别 | 效果 | 示例 |
|------|------|------|
| **被动道具** | 永久改变角色属性 | 伤害 +2、移速 +15% |
| **主动道具** | 消耗充能释放效果 | 护盾、伤害波、治疗 |
| **仪式道具** | 满足条件后触发 | 献祭心、特殊效果 |
| **组合道具** | 与其他道具产生互动 | 伤害 +50%，对满血无效 |

### 5.2 道具品质

| 品质 | 颜色 | 概率 | 说明 |
|------|------|------|------|
| 普通 (Common) | 白色 | 60% | 基础属性提升 |
| 稀有 (Rare) | 蓝色 | 20% | 独特效果 |
| 传说 (Epic) | 紫色 | 12% | 强力且独特的效果 |
| 神话 (Legendary) | 金色 | 5% | 改变玩法的核心道具 |
| 诅咒 (Cursed) | 黑色 | 3% | 有副作用的强大效果 |

### 5.3 道具示例

#### 被动道具

| **My Reflection** | 稀有 | 发射反向弹幕（反弹敌方子弹） |
| **Sacrificial Dagger** | 传说 | 可献祭半颗心，获得强力增益 |

```
普通池 (60%): 属性提升类，伤害/射程/速度等
```

## 9. 美术风格

### 9.1 视觉方向

- **风格**: 手绘阴暗风格，类似以撒的涂鸦质感
- **色调**: 地下室层以灰色/褐色为主，随楼层加深逐渐变为红色/紫色
- **分辨率**: 像素艺术（pixel art），渲染时保持 crisp 的像素边缘
- **屏幕比例**: 16:9，支持窗口化和全屏

### 9.2 精灵规格

| 元素 | 尺寸 | 帧数 |
|------|------|------|
| 角色 | 32x32 | 4~8 帧/动作 |
| 敌人(小) | 16x16 | 2~4 帧/动作 |
| 敌人(大) | 32x32 | 4~8 帧/动作 |
| Boss | 64x64~128x128 | 8~16 帧/动作 |
| 子弹 | 8x8 | 1~2 帧 |
| 道具 | 16x16 | 动画循环 |
| 背景瓦片 | 32x32 | 静态 |

### 9.3 特效

- 子弹命中时的粒子效果
- 角色受伤闪烁
- Boss 阶段转换的屏幕震动
- 拾取物的发光动画
- 房间切换的淡入淡出

## 11. 游戏进度

### 11.1 单局进度

```
开始 -> 1F -> 2F -> 3F -> 4F -> Boss -> 结局
                  ↑
              可能有 B1+ 通往真结局
```

### 11.2 跨局进度

| 进度类型 | 说明 |
|----------|------|
| 角色解锁 | 通过达成条件解锁新角色 |
| 道具解锁 | 新道具加入掉落池 |
| 成就 | 记录玩家行为，解锁额外内容 |
| 难度解锁 | 通关后解锁更高难度模式 |
| 真结局 | 满足特定条件后解锁最终Boss |

| 结局 | 条件 | 说明 |
